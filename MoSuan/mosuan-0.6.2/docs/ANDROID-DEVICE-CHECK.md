# 墨算 0.6.0 Android 实机验收

用平时使用的手机覆盖安装 `artifacts/android/mosuan-0.6.0-android.apk`，保留旧版和现有笔记。准备 [120 组公式长文](../artifacts/mobile-stress/墨算手机公式压力测试.md) 与 [积分题图](../artifacts/android-device-check/integral-question.png)。

| 顺序 | 手机上怎么做 | 通过标准 |
| --- | --- | --- |
| 1. 导入和重开 | 打开墨算，检查旧笔记。用「导入文本」选长文，搜索第 060 组的 `MID-060`，再跳到末尾。关闭墨算并重开。 | 旧笔记仍在。长文能恢复，能看到矩阵、公式、代码和 `FINAL-OK-20261105`。 |
| 2. 带图提问 | 新建一段对话，上传积分题图。请 DeepSeek 用两种方法解答并写出步骤。 | 输入框显示题图预览，回答可在墨算中查看，积分结果为 $1/3$。 |
| 3. 切后台和断网 | 收到一段正文后切到桌面，几秒后回来。另发一次问题，在收到正文后关闭 Wi-Fi 和移动数据。等待连接错误，或点「停止生成」。重开墨算，再恢复网络。 | 已保存的正文和题图仍在，未结束的回答有状态提示。点「重试」能重发题目，点「从这里继续」能保留旧正文并生成续写。 |
| 4. 保存并打开文件 | 对带题图的对话，从顶部导出菜单保存 Word。导出 PDF 时在系统打印界面选「另存为 PDF」。去文件管理器打开实际保存的两个文件。 | 两个文件可打开，能看到中文、公式、题图和末段。仅看到打印或保存窗口还不算保存完成。 |
| 5. 备份和恢复 | 给带题图的笔记置顶。在「设置 → 备份与恢复」保存整库文件，将文件传到电脑或另一台手机，打开恢复预览后确认。 | 预览能看到题图和置顶数量。恢复后问答、公式原文、题图和置顶状态一致。已有笔记保留，重复恢复会跳过相同笔记。 |

记录手机型号、Android 和 WebView 版本。长文可分别在 KaTeX 与 MathJax 下记录首屏用时、快速滚动后的空白持续时间和导出用时。若遇到异常，记录对应步骤、屏幕提示和发生前的操作。

## 电脑上的长文测量

使用同一份约 186 KB、含 120 组推导与 2,000 多条公式的样本。Edge 采用 390 × 844 视口和 4 倍 CPU 降速，流式回放分 18 段。下面是本次记录，手机实测时间应单独填写。

| 项目 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 流式回放中主线程长任务总时间 | 5.21 秒 | 4.19 秒 |
| 流式回放中最长单次任务 | 558 毫秒 | 393 毫秒 |
| 16 次跳读到两个动画帧后的中位时间 | 270 毫秒 | 203 毫秒 |
| 16 次跳读中同时挂载的块数峰值 | 16 | 14 |
| 带题图的 PDF HTML 排版 | 22.58 秒 | 17.85 秒 |
| 带题图的 Word 文件生成 | 33.06 秒 | 29.66 秒 |

长文改用本机 Worker 解析，流式生成时复用已经显示的公式。开发服务首次加载 Worker 的记录有一次约 9.5 秒。另用生产构建检查原始压力文档，从选择文件到 1,743 个阅读块就绪约 0.34 秒，其中 Worker 启动及返回约 77 毫秒。PDF 计时止于生成 HTML，实际系统打印和文件打开按上表在手机上检查。
