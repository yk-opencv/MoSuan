# 墨算 Android 安装与使用

Android 版使用 Capacitor 原生封装，内置 KaTeX、MathJax 和公式字体。0.6.0 新增整库备份与恢复，并可在回答中断后重试或续写。导入、搜索、阅读、备份和 PDF / Word 导出可以离线使用。「手机网页直连」可在手机上完成文字和图片提问，也可选择电脑转发。

## 安装

1. 将 `artifacts/android/mosuan-0.6.2-android.apk` 传到手机。已有旧版时直接覆盖安装，保留本机笔记。
2. 如果系统询问是否允许当前文件管理器安装应用，按手机提示允许本次安装。
3. 安装后打开「墨算」。无需 Node.js 或 API Key，即可导入 Markdown / TXT、阅读公式和保存笔记。

0.6.1 可在「设置 → 语言」切换简体中文、繁體中文或 English。切换即时生效，选择保存在手机上。

0.6.2 可在导入预览中点击「检测公式格式」，核对排版后补齐独立公式的分隔符。正文里的公式可选中后点击「将选区设为行内公式」。

安装包最低 Android API 为 24（Android 7.0），建议保持 Android System WebView 更新。实际兼容性仍需在你的手机上验证。

## 导入、搜索与使用说明

1. 左上角菜单 →「导入文本 → 选择文件」。编码明确的 Markdown / TXT 会保存并打开，需确认编码时先显示预览。想先编辑文件内容或标题，勾选「导入前预览」。也可直接粘贴原文，点「导入并阅读」。
2. 左上角菜单 →「搜索笔记」。输入中文、英文或公式原文，如 `x^2` 或 `\frac`。结果标出命中内容，点击即可定位。搜索覆盖本机笔记标题与问答正文，图片内容不会参与搜索。
3. 左上角菜单 →「设置 → 使用说明」。可离线查看导入、阅读、DeepSeek 连接、图片提问和导出步骤。

导入支持 UTF-8、GBK / GB18030 和常见 UTF-16。中文预览不正确时可手动切换「文件编码」，也支持 Big5。导出 Markdown 统一使用 UTF-8，不覆盖原文件。0.6.0 已在小米 14 上完成长文导入、编码往返和备份恢复测试。[Android 实机结果](ANDROID-DEVICE-CHECK.md#小米-14-实机结果2026-11-06)

## 备份与恢复

在「设置 → 备份与恢复」点「备份全部笔记」，用系统窗口保存 `.mosuan.json`。目标设备打开「选择备份文件」，核对笔记、题图和置顶数量后点「确认恢复」。恢复会合并笔记，同内容跳过，同一条笔记有差异时保留为副本。单份备份上限为 64 MiB，文件只包含笔记数据。

## 回答中断后继续

切到后台时，墨算会尝试把已收到的正文写入本机。重开后，未完成回答下方显示已保存的内容与操作。「重试」重新发送原问题和图片，「从这里继续」会带上已收到的末段并追加续写。若要验证本机保存、断网恢复和系统导出，可按 [Android 实机验收步骤](ANDROID-DEVICE-CHECK.md) 操作。

## 手机独立调用网页版接口（实验功能）

1. 覆盖安装后打开「设置 → API 与连接」，选择「手机网页直连」。全新安装默认使用此方式；已配对的手机保留电脑转发，需要手动切换一次。
2. 点击「登录 / 打开 DeepSeek」。在手机网页中登录自己的账号，然后点击上方 **「保存登录并返回」**。0.2.0 的网页登录需要重新保存一次，以生成原生直连用的加密登录记录。
3. 回到墨算输入问题并发送，回答会直接流式显示、排版和保存。聊天时不跳转网页，不需要再次点击网页发送或「带回回答」。
4. 可以使用手机 Wi-Fi 或移动网络，电脑无需开机，也不需要电脑地址、配对码或开放平台 API Key。
5. 登录失效或网页要求验证时，重新进入登录页处理，再保存登录。设置中的「清除直连登录」只清除原生连接记录，不删除笔记；网页登录本身仍可在网页中退出。

这是个人网页版非公开接口接入，不是官方开放平台 API。原生客户端使用与电脑代理相同类型的会话、PoW 和流式协议；登录页只负责取得你在本机授权保存的 token、必要客户端字段和 cookies。它们使用 Android Keystore + AES-GCM 加密保存在 App 私有存储，不返回到墨算阅读页，也不发送到电脑或第三方服务器。手机号、密码、验证码仍直接在 DeepSeek 登录页输入，墨算登录适配脚本不读取这些输入框。

每次请求携带当前问题和所选完整历史轮次，创建独立网页会话，不读取网页旧对话。手机原生 HTTP 负责请求和流式传输，本地 Worker 计算服务要求的 PoW 校验，正文协议解析后交给 KaTeX / MathJax。错误、停止或断流保留已收到的内容；没有服务端完成标记时不会假定回答完整。停止会取消本机连接和计算，不保证 DeepSeek 服务端同时停止生成。网页端可能记录这些新会话。

0.4.1 支持在输入框选择、预览、移除并发送图片；历史含图时也按所选上下文携带。手机先为上传取得请求校验，使用 multipart 上传，等待图片状态成功，再把文件编号随问题提交。解析失败或超时会明确报错，不发送缺少图片的纯文字问题。暂不支持深度思考和联网搜索切换。

已在电脑上用已有个人网页登录完成一次原始接口真实合成问答（返回“2”），验证了当前会话协议、官方 PoW 模块、打包后的 Worker 和回答解析，没有调用付费 API。原生 HTTP 客户端另有 JVM 模拟测试；手机界面、登录消息和停止用 Edge 模拟。**尚未在 Android 实机上验证本版的登录保存与原生请求全流程**，电脑协议测试不能代替实机验证。

这是实验功能：非公开接口、验证、限流或网络策略改变都可能导致失败；不会自动重发、切换账号或转向付费 API。「登录已保存」仅表示本机存在连接资料，实际可用性以发送结果为准。需要较新的 Android System WebView 支持登录消息接口和 WebAssembly Worker。

## 通过电脑服务连接（可选）

在「API 与连接」中选择「电脑转发」，使用电脑上的官方 API 或网页版代理。这种方式下手机和电脑应在同一可信局域网内；校园网即使同名 Wi-Fi，也可能限制设备间访问。

1. 在电脑上停止已有墨算服务，再双击根目录的 `start-mobile-server.cmd`。该入口将服务监听到局域网，保持窗口运行。
2. 在电脑浏览器打开 `http://127.0.0.1:3001`，进入「设置 → API 与连接」，配置官方 API 或网页版代理。网页版代理仍需先登录并运行 `start-web-proxy.cmd`。
3. 点击「显示 Android 配对信息」，查看电脑的局域网地址与配对码。多个地址时，选择与手机 Wi-Fi 处于同一网段的地址。
4. 在手机 App 进入「设置 → API 与连接 → 电脑转发」，填写地址与配对码，点击「保存并检查连接」。
5. 连接就绪后即可提问。连接设置保存在手机；DeepSeek API Key 与网页登录文件继续由电脑端保存。

电脑端还提供 `/api/android-apk` 下载地址。例如手机浏览器访问 `http://电脑局域网IP:3001/api/android-apk`，即可直接下载安装包。也可在电脑的 Android 配对区域下载后传给手机。

如果连接失败，先在手机浏览器打开电脑的局域网地址，检查电脑服务、Wi-Fi 与 Windows 防火墙端口是否可达。`127.0.0.1` / `localhost` 在手机上表示手机本机，应填写电脑的局域网 IP。

## 图片提问

输入框底部的图片按钮支持 JPG、PNG、WebP、GIF，每条问题最多 7 张，每张原文件不超过 12 MB；发送前会在本机压缩并显示预览，也可以移除、粘贴或拖入图片。

图片随问题保存在本机笔记中，点击可以放大查看。手机网页直连和电脑转发模式中声明支持图片的网页版代理均可发送附件。官方文本接口或未声明图片能力的模型会提示切换连接，并保留草稿。图片识别效果和可用性取决于上游实际服务。

浏览器模拟与 Android 原生网络单元测试已验证单轮携带 7 张图片。0.6.0 的小米 14 实测确认题图可预览、保存和恢复，联网提问时遇到网页版限流，成功解答积分题图仍待补验。遇到限流时，问题与图片会保留供稍后重试。

## 文件与本机数据

- 「导入文本 → 选择文件」使用 Android 系统文件选择器；背景与题目图片通过系统图片选择器选取。
- 「导出 Markdown」打开 Android 系统保存窗口，可以自行选择文件位置。取消保存不会删除笔记。
- 下载按钮旁的下拉箭头打开「选择导出格式」；PDF 打开 Android 系统打印，在打印机列表选择「另存为 PDF」再确认保存。Word 生成 `.docx` 后打开系统文件保存窗口，正文和常用公式可编辑。无法转换的公式保留为图片或原文。两者包含整段对话与已保存题目附件，使用黑字白底，离线可生成，不附带连接配置。原生打印与 Word 保存仍需手机实机验证；电脑模拟检查不能代替系统界面测试。
- 「分享对话 → 系统分享」使用 Android 分享面板，可将 Markdown 文件交给目标应用。
- 手机和电脑的笔记分别保存在各自设备，不会自动互相同步。卸载 App 会清除手机中的笔记，请事先导出需要保留的内容。
- Markdown 导出包含题目图片的数据，但当前重新导入时只显示图片占位符，尚不支持含图对话的完整还原；需要图片原件时请另行保留。
- Android 返回键会先关闭图片预览、弹窗或侧栏；在主界面连续按两次返回键退出。

0.4.1 的导出样例已在 Windows 桌面 Word 中验证：Word 识别 7 个原生公式，修改分式的分子后保存并重开，仍可作为公式编辑。

本版不提供可靠的后台生成任务；长时间切到后台或关闭 App 后，应检查回答是否完整。

## 从源码构建（Windows）

首次安装项目依赖：

```powershell
npm ci
```

准备项目私有的工具链（需要联网，下载到 `.local/android-tools`，不修改系统 Java / SDK 设置）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-android.ps1 -Component jdk
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-android.ps1 -Component sdk
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-android.ps1 -Component gradle
```

然后双击 `build-android.cmd`，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

脚本构建页面、同步原生资源、编译 release APK、签名并校验，输出安装包与 SHA256 文件到 `artifacts/android/`。签名材料保存在 `.local/android-signing/`，需要自行备份以便后续版本继续更新；该目录不进入源码仓库或 APK。

技术参考：[Capacitor Android 环境](https://capacitorjs.com/docs/getting-started/environment-setup)、[Android HTTP 连接](https://developer.android.com/reference/java/net/HttpURLConnection)、[受来源限制的网页消息接口](https://developer.android.com/reference/androidx/webkit/WebViewCompat)、[协议与 PoW 参考项目](https://github.com/dekrezz/FreeDeepseekAPI)。PoW ABI 适配部分保留 Apache-2.0 许可，完整文本随 App 打包在 `licenses/FreeDeepseekAPI-LICENSE.txt`。
