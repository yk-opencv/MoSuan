# 墨算 0.6.2 快速开始

墨算可导入 Markdown 或 TXT 笔记、阅读 LaTeX 公式、搜索长对话、备份和导出。简体中文、繁體中文和 English 可在「设置 → 语言」即时切换。导入和阅读可离线使用。0.6.2 在导入预览中新增「检测公式格式」，可核对预览、补齐独立公式的分隔符，或将选区设为行内公式。

## Windows

1. 解压 `mosuan-0.6.2-project.zip`，进入 `mosuan-0.6.2`。
2. 安装 Node.js 22.12 或更高版本，推荐使用 Node.js 24。
3. 双击 `start-packaged.cmd`，在浏览器打开窗口显示的地址，默认是 [http://127.0.0.1:3001](http://127.0.0.1:3001)。使用期间保持窗口运行。

发行包已包含编译后的页面。需要修改源码时，在项目根目录运行 `npm ci` 和 `npm run build`，再启动墨算。其他用法见 [项目说明](README.md)。

## Android

将 `mosuan-0.6.2-android.apk` 传到手机并安装。压缩包内也可在 [artifacts/android](artifacts/android/) 找到同一个 APK。Android 7.0 及以上可安装，已有相同签名的墨算可覆盖更新。操作步骤见 [Android 安装与使用](docs/ANDROID.md)。

## 连接 AI

电脑使用官方 API 时，将 `.env.example` 复制为 `.env`，填入自己的 DeepSeek API Key 后重新启动。电脑端的实验性网页版代理需要另行准备 [FreeDeepseekAPI](https://github.com/dekrezz/FreeDeepseekAPI) 并登录自己的账号。Android 端可按安装说明配置手机网页直连或电脑转发。
